# Primeiro prompt para o Codex

Leia integralmente `base.md` e `AGENTS.md`, depois todos os arquivos em `docs/` e `CHANGELOG.md`. Considere `base.md` a fonte principal dos requisitos.

Quero começar **somente a Etapa 1** de `docs/development-plan.md`. Antes de escrever código, inspecione o repositório e informe: (1) o que já existe, (2) versões atuais estáveis de Laravel e PHP compatíveis, confirmadas com as ferramentas/documentação disponíveis, (3) plano de implementação, (4) arquivos que pretende criar/alterar e (5) comandos de verificação.

Depois, implemente somente o que foi autorizado para essa etapa, seguindo Laravel nativo, Blade e arquitetura monolítica, com testes apropriados. Não crie API separada, SPA, funcionalidades futuras ou infraestrutura desnecessária. Rode os testes e o formatter disponíveis, registre resultados reais e atualize `CHANGELOG.md` com feito/validado/pendente. Não faça commit nem avance à Etapa 2 sem minha aprovação. Se faltar uma decisão importante, pergunte antes de implementar.
